# Sistema de Gerenciamento de Filmes

Este sistema tem como objetivo fornecer funcionalidades para a gestão de sessões de filmes em uma plataforma de venda de ingressos online para um cinema.

## Funcionalidades

### 1. Exibição de Filmes Disponíveis e Suas Sessões
- O sistema buscará e exibirá uma lista dos filmes disponíveis junto com as sessões correspondentes.
- O usuário poderá visualizar detalhes como horários das sessões e salas.

### 2. Sistema de Cadastro de Usuário (Opcional) / Assinatura
- Os usuários podem se registrar.

### 3. Sistema de Compra de Ingressos
- **Conferência de Disponibilidade**: Verifica a disponibilidade de ingressos para o filme selecionado.
- **Opção de Pagamento**: Permite a escolha de métodos de pagamento disponíveis e verifica a validade do mesmo.
- **Meia Entrada**: Habilita a verificação e aplicação de meia entrada, caso aplicável.
- **Verificação de Entrada**: Confirma a validade do ingresso e libera o acesso ao filme.
